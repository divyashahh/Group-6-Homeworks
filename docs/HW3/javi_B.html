  2. What are the major benefits of using R projects?

    • R projects helps organize the workflow by keeping all the relates files in a single folder. It sets the working directory to the project folder root, so no need to use setwd(). Allows the users to have different RStudio windows with different projects. It easily pairs with Git.

  3. What is Git and what is GitHub?

    1. Git is the version control system software that runs locally and keeps track of all the changes to files overtime (commits and different branches from users). Github is the website the hosts these Git repositories in the cloud so it is easier to share with others. They work together when we push the progress we have done on our code and pushes it to Github to back up the code and allow peers to review, comment, or edit it.

  4. What are the two main differences between a tibble and a data.frame?

    1. A tibble displays a clean and compact version preview showing only 10 rows and 10 columns that fit your console and also lists the data type, whereas a data.frame prints out the entire dataset forcing the user to scroll through it. Also, subsetting a tibble using [] will always return another tibble, without dropping a bare vector like data.frame does by default. Tibbles also do not need partial name matching with the $.

Task 4: Writing a Function

  1. Write a basic function (call it getIQR) that takes in a vector of numbers and returns the interquartile range (75th percentile - 25th percentile). You can use the quantile function. Remove the name on the returned vector (i.e. make sure the returned item doesn’t have a name like 75% or something like that). Allow your function to pass unnamed arguments to the quantile function.

    getIQR <- function(x, ...) { # ... =  trim = 0, na.rm = FALSE, ...
  q <- quantile(x, probs = c(0.25, 0.75), ...)
  unname(q[2] - q[1])
}
