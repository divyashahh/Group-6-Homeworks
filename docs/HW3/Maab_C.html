2.R projects are great because they provide automatic working directory management, since R sets the working directory to the project’s folder instead of requiring a manual setwd() call each session. Everything related to the project (scripts, data, .qmd files) is in one folder, making it easy to move, zip up, or clone fresh from GitHub. R projects also maintain their own separate environment and work directly with Git through RStudio’s Git tab, since the project root and Git repo root are typically the same folder, keeping tracking, committing, and pushing all lined up cleanly.

3.Git is a version control system that takes snapshots of r projects and stores the history on the local computer. while GitHub is a website that gives online storage area for repositories. This allows collaborations with other members through push and pull request features. The main difference is that Git tracks changes locally, while GitHub hosts that history remotely and enables collaboration between multiple people.

4.The first main difference between tibble and a data.frame is how they are printed. tibble is presented in a much more organized and useful way where as data.frame is less organized and overwhelming.The second difference is that a tibble has multiple classes (tbl_df, tbl, data.frame), while a data.frame has only one (data.frame). This extra class structure lets R apply special tibble behavior (like the fancy printing) through method dispatch, while still falling back to standard data.frame behavior when needed.

In this section we write functions to get the IQR and coefficient of variation individually then together via getSummaries(). Additionally we write an infix function that can be used in replace of the cbind function.

# making the getIQR function 
getIQR <- function(vector,...) {
  q_75<- quantile(vector,0.75,...)
  q_25<- quantile(vector,0.25,...)
  IQR<- unname(q_75 - q_25) 
 
  return(IQR)
}

Making getCoefVar() that returns the sample coefficient of variation, defined as the sample standard deviation divided by the absolute value of the sample mean.

# making the getCoefVar function 
getCoefVar <- function(vector,...) {
  stand_dev<- sd(vector,...)
  abs_mean<- abs(mean(vector,...))
  CoefVar<- unname(stand_dev/ abs_mean) 
 
  return(CoefVar)
}

Making getSummaries a function that takes in a vector and returns both the IQR and the coefficient of variation using the two functions above.

# making the getSummaries function 
getSummaries <- function(vector,...) {
  IQR<- getIQR(vector,...)
  CoefVar<- getCoefVar(vector,...)
 
 
  return(list("IQR" = IQR , "CoefVar" = CoefVar))
}
