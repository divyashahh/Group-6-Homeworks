Task 4: Writing Functions

Interquartile Range Function

First, I create a function called getIQR that calculates the interquartile range by subtracting the 25th percentile from the 75th percentile. The returned value is unnamed, and additional arguments can be passed to quantile().

getIQR <- function(x, ...) {
  result <- quantile(x, 0.75, ...) - quantile(x, 0.25, ...)
  unname(result)
}

I apply the function to the fixed_acidity and citric_acid columns of the combined wine data.

getIQR(wine_data$fixed_acidity)
[1] 1.3
getIQR(wine_data$citric_acid)
[1] 0.14

Coefficient of Variation Function

Next, I create a function called getCoefVar that calculates the sample coefficient of variation as the sample standard deviation divided by the absolute value of the sample mean.

getCoefVar <- function(x, ...) {
  sd(x, ...) / abs(mean(x, ...))
}

I apply this function to the same two variables.

getCoefVar(wine_data$fixed_acidity)
[1] 0.1796783
getCoefVar(wine_data$citric_acid)
[1] 0.4560663

Summary Function

Next, I create a wrapper function called getSummaries. This function calls the two functions created above and returns both the IQR and coefficient of variation with appropriate names.

getSummaries <- function(x, ...) {
  c(
    IQR = getIQR(x, ...),
    CoefVar = getCoefVar(x, ...)
  )
}

I apply the summary function to the fixed_acidity and citric_acid variables.

`%cbind%` <- function(x, y) {

}
