2. Long vs. wide format data

In long format, each row is a single observation of a single variable, with a column identifying which variable/group/timestamp it belongs to. In wide format, each subject/unit gets one row, with repeated measurements or variables spread across separate columns.

Long format is generally preferred for statistical analysis, since most plotting, summarizing, and modeling functions in R expect one row per observation — it makes filtering, grouping, and analysis cleaner.

yeast_summary <- yeast |>
  select(-seq_name, -nuc) |>
  group_by(class) |>
  mutate(
    across(
      c(mcg, gvh, alm, mit, erl, pox, vac),
      list(
        mean = ~mean(.x, na.rm = TRUE),
        median = ~median(.x, na.rm = TRUE)
      )
    )
  ) |>
  ungroup()
