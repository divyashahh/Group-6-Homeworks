  1. We write a quick function that allows the user to easily query this API. The inputs to the function are the title/subject to search for, a time period to search from, and an API key.
get_info <- function(query, from_date, api_key) {
  response <- GET("https://newsapi.org/v2/everything",
                   query = list(q = query,
                                from = from_date,
                                language = "en",
                                pageSize = 50,
                                apiKey = api_key))

  parsed <- content(response, as = "parsed", simplifyDataFrame = TRUE)

  if (parsed$status != "ok") {
    stop("NewsAPI request failed: ", parsed$message)
  }

  as_tibble(parsed$articles)
}

Our findings :

Overall we found that inversions are strongly tied to both coaster type and ride intensity. Steel coasters are considerably more likely to include inversions than Wood coasters, and notably, every coaster with inversions in the dataset falls under the “Extreme” scale category, with none present among Family, Kiddie, or Thrill rides. This suggests that inversions are less a general design feature and more a defining characteristic of the most intense, steel-built coasters.The side-by-side and a stacked bar graph comparing coaster type and inversion status, both visually confirmed that inversions are far more common among Steel coasters than Wood coasters.
