  3. Now write a quick function that allows the user to easily query this API. The inputs to the function should be the title/subject to search for (string), a time period to search from (string - you’ll search from that time until the present), and an API key.

    get_news <- function(query, from_date, api_key) {
  response <- GET("https://newsapi.org/v2/everything",
                   query = list(q = query,
                                from = from_date,
                                language = "en",
                                pageSize = 50,
                                apiKey = api_key))

  parsed <- content(response, as = "parsed", simplifyDataFrame = TRUE)

  if (parsed$status != "ok") {
    stop("NewsAPI request failed: ", parsed$message)
  }

  as_tibble(parsed$articles)
}
