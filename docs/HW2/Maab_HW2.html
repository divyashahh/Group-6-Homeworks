Task 4: Control Flow Practice

In this section I add a status column to each data frame inside the list, then use a for loop with if/else logic to classify each patient as optimal, borderline, or high based on their post treatment/placebo blood pressure values.

#creating a status column in treatment and placebo:
bp_list$treatment$status<- character(20)
bp_list$placebo$status<- character(10)

#creating loop for treatment data frame with conditions optimal (≤ 120), borderline (120 < bp ≤ 130), and high (> 130).
for (i in 1:nrow(bp_list$treatment)){
  
  if(bp_list$treatment$post_bp[i] <= 120) {
    bp_list$treatment$status[i]<- "optimal" 
    
  }else if (bp_list$treatment$post_bp[i] > 120 & bp_list$treatment$post_bp[i] <= 130) {
    bp_list$treatment$status[i]<- "borderline" 
    
  }else {
    bp_list$treatment$status[i]<- "high" 
  }
}
