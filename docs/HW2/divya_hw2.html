Task 4: Control Flow Practice

For this task, I classify each subject’s post-treatment blood pressure as optimal, borderline, or high. I add a new status column to each data frame stored in the list and use for loops with if/else logic to assign the appropriate category.

1. Create the status columns

First, I create an empty character column called status in both the treatment and placebo data frames stored inside bp_list.

# Create empty status columns in the data frames stored in the list
bp_list$treatment$status <- character(nrow(bp_list$treatment))
bp_list$placebo$status <- character(nrow(bp_list$placebo))

2. Assign status for the treatment group

I loop through each row of the treatment data frame and classify the post-treatment blood pressure. Values less than or equal to 120 are classified as optimal, values greater than 120 and less than or equal to 130 are classified as borderline, and values greater than 130 are classified as high.

# Assign blood pressure status for the treatment group
for (i in 1:nrow(bp_list$treatment)) {
  
  if (bp_list$treatment$post_bp[i] <= 120) {
    bp_list$treatment$status[i] <- "optimal"
    
  } else if (bp_list$treatment$post_bp[i] <= 130) {
    bp_list$treatment$status[i] <- "borderline"
    
  } else {
    bp_list$treatment$status[i] <- "high"
  }
}
